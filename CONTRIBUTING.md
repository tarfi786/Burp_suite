# Contributing notes

This is a personal learning repository. Keep contributions factual and safe.

## Documentation checklist

- State the authorized lab or environment.
- Record the tool and version used.
- Explain the steps in your own words.
- Include observed results, not assumed results.
- Mark unfinished work as in progress.
- Sanitize screenshots and request/response examples before committing.
- Do not include secrets, private keys, session cookies, or personal data.
