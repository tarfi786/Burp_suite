# Security and responsible disclosure

This repository is a learning portfolio, not an invitation to test third-party systems.

- Test only systems you own or have explicit permission to assess.
- Use designated training labs for security exercises.
- Never commit passwords, API keys, session cookies, bearer tokens, private keys, or real user data.
- Review screenshots and HTTP examples before publishing.
- If sensitive data is accidentally committed, removing it in a later commit may not remove it from Git history. Revoke or rotate exposed credentials and follow GitHub's guidance for removing sensitive data.

If you discover a vulnerability in a real service, follow that service's authorized disclosure process.
